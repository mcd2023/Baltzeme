BALTZEME INVEST SIA — STATIC WEBSITE PACKAGE

This ZIP contains a standalone, responsive version of the BaltZeme corporate page.
It does not require WordPress, React, Next.js, a database or a build process.

FILES
• index.html  — page structure and content
• styles.css  — complete desktop and mobile styling
• script.txt  — JavaScript code; rename this file to script.js before uploading

INSTALLATION
1. Extract the ZIP archive.
2. Rename script.txt to script.js. (The .txt name is used only because Gmail blocks .js attachments.)
3. Upload index.html, styles.css and script.js together to the website root or the desired subdirectory.
4. Keep all three files in the same folder.
5. Open index.html in a browser to test the page.
